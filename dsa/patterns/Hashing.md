# Hashing

Used when:
- duplicate detection
- frequency count
- key value lookup
- complement value
- comparing collections

And whenever you hear:
- “Have I seen this before?”
- “Can I check existence fast?”
- “Can I find complement fast?”
that is a lookup.

Usually:
Time O(n), Space O(n)
